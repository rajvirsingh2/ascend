# Ascend App — Google Stitch UI Design Prompt

Copy and paste the following prompt into Google Stitch (or any other AI UI generation tool) to generate UI mockups for Ascend.

---

**Prompt:**

Design a premium mobile app dashboard for a gamified productivity and habit-tracking app called "Ascend", heavily inspired by "Solo Leveling" and modern RPG video games. 

**Aesthetic & Vibe:**
Dark mode, sleek, slightly futuristic, and highly motivational. It should feel like a high-tech hunter's interface. 
**Color Palette:** Deep black/void backgrounds (`#0D0D12`), neon cyan accents (`#00F0FF`), glowing arcane purple highlights (`#7C3AED`), and gold (`#FFD700`) for rewards. Panels should have subtle glassmorphism and glowing borders.

**Key UI Elements to Include:**

1. **Player Header:** 
   - A sticky top section showing the user's codename (e.g., "HUNTER JINWOO").
   - A glowing Rank Badge (e.g., "S-Class").
   - Current Level (e.g., "LVL 12").
   - An HP (Health) bar in neon red showing 85/100 HP.

2. **XP Bar:** 
   - A sleek, high-tech horizontal progress bar glowing with cyan or purple to show progress to the next level. Include a glowing particle effect at the leading edge.

3. **Action Button:** 
   - A large, prominent button with a glowing gradient border and a subtle pulse effect that says "⚔ GENERATE NEW QUESTS". 

4. **Active Quests Section:** 
   - A list of "Quest Cards" under a section titled "◈ ACTIVE QUESTS" (with cyan text). 
   - Each card should look like a mission briefing containing:
     - Quest title (e.g., "10 KM RUN").
     - A difficulty badge (e.g., 4 skulls or stars).
     - The skill area (e.g., "Endurance").
     - A gold XP reward tag (e.g., "+150 XP").
     - A "SKIP" outline button and a solid glowing purple "COMPLETE QUEST" button.

5. **Daily Missions:** 
   - A section for daily habits titled "◈ DAILY MISSIONS".
   - Show habit titles (e.g., "Morning Meditation").
   - Include a streak counter (e.g., "12-DAY STREAK" in gold).
   - A satisfying circular neon checkmark button for completion.

Keep the typography sharp, capitalized, and modern (like Inter, Roboto, or Orbitron). The UI must look premium, not cartoonish.
